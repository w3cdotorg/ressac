# Ressac Sea Chart (Sub-project 6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Sea Chart" window in Ressac.app that draws the living feeds as an engraved sea chart (harbour and theme views, territories, continents, activity lights, animated sea), fed by `ressac chart --json`, with per-feed themes and territories in schema v5.

**Architecture:** The core owns the data: schema v5 (`theme`, `feed.theme_id`, `territory`, `territory_feed`), a store module for themes, territories, import and the chart snapshot, and three CLI entry points. The page is a bundled, offline web page ported from the mockup, split into a DOM-free `chart-core.js` (layout, coasts, labels, heat; tested under Node) and `chart-draw.js` (canvas, animation, interaction). The app hosts it in a WKWebView window, reruns the CLI when the database changes, and relays clicks.

**Tech Stack:** Rust 2024 (rusqlite, serde, clap, insta), JavaScript (classic scripts, d3 7.9.0 bundled, Node `node --test` for tests, no npm dependencies), Swift 6 / SwiftUI / AppKit WKWebView, XcodeGen.

**Spec:** `docs/specs/2026-10-19-sea-chart-design.md` (*the spec*). Visual reference: the mockup source at `/private/tmp/claude-504/-Users-willow-Sites--Claude-output/6243d9dc-3f62-4688-9919-317b4b8a36c3/scratchpad/carte/` (`head.part` CSS, `body.part` HTML and script, `build.py`, `themes.py`); read it, never copy its data.

## Global Constraints

- **Schema:** v5 exactly as spec §4; migration with backup like v3 and v4; `AppDatabase.knownSchemaVersion` = 5 in the same task.
- **Chart feeds:** `feed.state = 'active'`, not waiting for triage (`needs_triage = 0` in `feed_health`, as `v_garden_row` exposes it), and last entry `published_at` ≥ now − 182 days; nothing else filters.
- **Activity:** Σ over entries published in the last 30 days of `2^(−max(0, age_days)/3)`; `unread_week` and `entries_week` count entries published in the last 7 days.
- **Contract:** JSON `version: 1`, fields exactly as spec §6; unthemed feeds `"theme": null`, drawn in `UNCHARTED WATERS`, last sector.
- **Views:** harbour: port (960, 560), RX 830, RY 430, `ringFrac(age) = .13 + .87 · min(1, ln(1+age)/ln(1+182))^.5`; rings 1, 7, 30, 91, 182 days labelled `1 day`, `1 week`, `1 month`, `3 months`, `6 months`. Chart space 1920 × 1080, grid cell 4.
- **Island radius by rhythm:** daily 36, weekly 27, monthly 21, rare 16, silent 11 (× 0.7 in the harbour view).
- **Inks:** `bleu`, `nuit`, `pop`, `pirate` with the mockup's paper/ink/dot/land/label/beam/ripple values and heat ramps (blue `#d9ece2 #a7d3c0 #e9cf72 #dd9a3c #b8642a #8a4417`; night `#24504c #3f9c92 #7fd3c4 #ecd77f #ffb347 #ff9433`; pop `#c9f2e9 #6fd0c1 #ffd166 #ff9a76 #ef476f #b5174f`; pirate `#c2cfa6 #8fae86 #d8b14a #c98a2e #9c5a1c #6e3510`).
- **Strings:** English on the chart and in the app; `notes.md` in French, no em dash in French prose.
- **Offline:** the page loads nothing from the network; navigation away from the bundle is cancelled; only http/https URLs are opened, through `NSWorkspace`.
- **Never** touch `~/Library/Application Support/Ressac/ressac.sqlite`; Rust and Swift tests use temporary databases.
- **Gate (every task):** `cargo fmt --all` then `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `INSTA_UPDATE=no cargo test --workspace`; from Task 5, also `node --test apps/macos/ChartTests/`; Swift tasks also run `cd apps/macos && xcodegen generate && xcodebuild -project Ressac.xcodeproj -scheme Ressac -destination 'platform=macOS' -derivedDataPath "$TMPDIR/ressac-dd" test`.

## Review Focus

1. **A feed title or entry title with HTML or quotes** reaches the page as data: the popover and labels must use `textContent`/canvas text, never `innerHTML` with feed text (Task 6 test `feed_text_is_never_html`).
2. **A JSON document larger than a few hundred kilobytes** (100 feeds × 5 entries) must pass from Swift to the page without being spliced into a script string unescaped: pass it through `callAsyncJavaScript` arguments (Task 8).
3. **A database migrating or busy while the chart refreshes** must leave the last good chart on screen and retry on the next change, never a blank window (Task 7 `failed_refresh_keeps_last_chart`).
4. **Zero chart feeds** (new database, everything older than 6 months): the page draws the sea, the harbour and the message "No feed has published in six months" (Task 6).
5. **Theme deleted by a re-import** while feeds point at it: `ON DELETE SET NULL` makes them unthemed, and the chart puts them in UNCHARTED WATERS (Task 2 `reimport_drops_a_theme`).

### Task 2: Themes, territories and import (core)

**Files:** Create `crates/ressac-core/src/store/chart.rs`. Modify `store/mod.rs` (`mod chart; pub use chart::…`), `crates/ressac-core/src/error.rs` (`UnknownTheme(String)` → `"No theme \"{0}\"."`).

**Interfaces (produced):**
```rust
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)] pub struct ThemeDef { pub key: String, pub name: String, pub sea: String }
#[derive(Debug, Clone, PartialEq, Deserialize)] pub struct TerritoryDef { pub name: String, #[serde(default)] pub feeds: Vec<String>, #[serde(default)] pub continent: Option<String> }
#[derive(Debug, Clone, PartialEq, Deserialize)] pub struct ChartImport { pub themes: Vec<ThemeDef>, #[serde(default)] pub feeds: BTreeMap<String, String>, #[serde(default)] pub territories: Vec<TerritoryDef> }
#[derive(Debug, Clone, PartialEq, Default, Serialize)] pub struct ChartImportReport { pub themes: usize, pub feeds_themed: usize, pub territories: usize, pub unmatched_urls: Vec<String>, pub unknown_theme_keys: Vec<String>, pub unthemed_feeds: usize }
impl Store {
  pub fn themes(&self) -> Result<Vec<ThemeDef>>;                       // by position
  pub fn set_feed_theme(&self, feed: FeedId, key: Option<&str>) -> Result<()>;  // UnknownFeed / UnknownTheme
  pub fn import_chart(&self, import: &ChartImport, dry_run: bool) -> Result<ChartImportReport>;
}
```
`import_chart`: one transaction; upsert themes by key with `position` = index; delete themes not in the file (their feeds become NULL); feeds matched by `xml_url` or `xml_url_original`; territories table emptied then refilled (a `TerritoryDef` with `continent` → kind continent with that theme; with `feeds` → kind territory, positions in file order, unmatched URLs reported); dry run rolls back and still reports.
