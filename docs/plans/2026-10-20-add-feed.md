# Ressac Add a Feed (Sub-project 7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one feed by its feed address or a site address (first announced feed), from File ▸ Add Feed… (⌘N) and `ressac add`; move feeds into folders by drag and drop and `ressac feed move`; a new feed inherits the sea chart theme and territory of a feed from the same host.

**Architecture:** The core gains `Store::move_feed` (with a shared lowest-free-page helper in `pages.rs`), a store-level insert for an added feed with sibling theme/territory inheritance, and `Ressac::add_feed` (resolve through the guarded client, discovery, duplicate check, insert, immediate `refresh` of that feed). The CLI exposes `add` and `feed move`. The app adds a sheet and sidebar drag and drop, both running the CLI through the existing run machinery. Schema unchanged (v5).

**Tech Stack:** Rust 2024 (rusqlite, reqwest through the guarded client, scraper via `discover`, clap, insta, wiremock), Swift 6 / SwiftUI, XcodeGen.

**Spec:** `docs/specs/2026-10-20-add-feed-design.md` (*the spec*; §2b holds the calls made after the builder check).

## Global Constraints

- **Schema:** unchanged, v5. Writes only through core functions; the app runs the CLI.
- **Input:** trimmed; no scheme → `https://`; only http/https; private addresses refused by the guarded client; existing size and time limits.
- **Discovery:** the **first** feed of `discover::alternate_feeds`; none, or the first not parsing → "This page announces no feed." (exit 2).
- **Duplicates:** `url_key` of the typed address and of the resolved feed address against `xml_url` and `xml_url_original` of every feed (buried included) → "Already followed: <title>." / "Already in the Cemetery: <title>." (exit 2), nothing written.
- **Insert:** root (`folder_id` NULL), position last among root feeds, page via `pages::assign_missing` (110–199), title from the feed else the host, `xml_url` = `xml_url_original` = the resolved address.
- **Same site:** same host, leading `www.` removed (not `url_key::site_of`). Majority theme among active siblings (tie → lowest feed id's); join the lowest-id `territory` (kind territory, never continent) a sibling belongs to. `--theme` wins over inheritance; unknown key refused before writing.
- **Fetch:** right after insert, `refresh` with `only = [id]`, `force`; a failed fetch keeps the feed.
- **Move:** position last in the target; page = lowest free in the target's range per `assign_missing` rules (subfolder → its root folder's range, overflow root folder → overflow pool, root → 110–199), else keep; no-op if already there.
- **CLI strings:** `Added #<id> <title> (page <n>)`, `Theme: <name> (same site as <title>)` or `Theme: none (Uncharted waters)` or `Theme: <name> (chosen)`, `Territory: <name>`; `Moved #<id> <title> to <folder|the root> (page <old> → <new>)`. Feed text through `output::printable`. `--json add` ends with an `added` event `{type:"added", id, title, xml_url, page, theme, territory, discovered}`.
- **App strings:** menu "Add Feed…" ⌘N; sheet title "Add a Feed", field placeholder "Feed or site address", pop-up "Theme" (None + themes by position), buttons "Add" / "Cancel"; success note "In <theme name>, like <sibling title>." when inherited.
- **Language:** English in code, CLI and app; notes.md French without em dash.
- **Never** the real database or the real network in tests (tempdirs, wiremock).
- **Gate:** `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `INSTA_UPDATE=no cargo test --workspace`, `node --test 'apps/macos/ChartTests/*.test.cjs'`; Swift tasks also `cd apps/macos && xcodegen generate && xcodebuild -project Ressac.xcodeproj -scheme Ressac -destination 'platform=macOS' -derivedDataPath "$TMPDIR/ressac-dd" test`.
- **Step 0** on files over 300 lines; **commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01AuT5b6J38qtEBs4rgmJ6rb`.

## Review Focus

1. **A site whose first announced feed is relative or protocol-relative** (`/feed.xml`, `//cdn…/rss`) must resolve against the page URL (discover already joins; test it through `add_feed`).
2. **A page that redirects** (http → https, apex → www) must use the final URL as the base for discovery and for the stored `html_url`.
3. **Adding while a refresh runs** (app or terminal): the add's fetch must not deadlock or corrupt; the existing busy/locking rules apply (the CLI waits like `fetch`).
4. **Dragging the selected feed** while its entries are listed: selection and entry list follow the feed, no crash on a stale index.
5. **A title with control characters or HTML** from the new feed: printable in the CLI, plain text in the app.
